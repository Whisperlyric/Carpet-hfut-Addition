## Build

This project uses the upstream [ReplayMod Preprocessor](https://github.com/ReplayMod/preprocessor) (not a fork) for single-source multi-version support. The main project is `1.21.1` (see `versions/mainProject`); other versions' sources are generated by the preprocessor. `versions/mapping-*.txt` take part in preprocessing in strict ExtraMapping format (`strictExtraMappings = true`) — add entries only when the automatically derived mappings are insufficient (e.g. a rename not derivable from the MC jars); syntax is documented at the top of each file.

```bash
# Build all versions and gather jars into build/libs/
./gradlew buildAndGather

# Build a single version
./gradlew :1.21.1:build
./gradlew :26.2:build

# Run client / server
./gradlew :1.21.1:runClient
./gradlew :1.21.1:runServer
```

> 26.x versions are unobfuscated (named mappings) and require JDK 25; 1.21.x versions require JDK 21. Running Gradle itself on JDK 25 builds everything.

## Project Structure

```
Carpet-Hfut-Addition-master/
├── build.gradle            # preprocessor version nodes and links
├── common.gradle           # shared build logic for all version subprojects
├── settings.gradle         # registers version subprojects from settings.json
├── settings.json           # supported version list
├── gradle.properties       # basic mod info
├── libs/                   # local dependency jars (GCA, compile-time via flatDir)
├── docs/                   # rule / command / API docs (zh/en)
├── .github/workflows/      # CI: dev builds / mixin audit / multi-version release
├── versions/
│   ├── mainProject         # main version name (1.21.1)
│   ├── mapping-*.txt       # inter-version extra mappings (strict ExtraMapping format)
│   ├── 1.21.1/             # version subprojects
│   │   └── gradle.properties
│   └── ...
└── src/main/
    ├── java/dev/whisperlyric/carpet_hfut_addition/
    │   ├── HFUTServerMod.java      # ModInitializer entry
    │   ├── HFUTServer.java         # CarpetExtension (rules/loggers/commands/translations)
    │   ├── HFUTSettings.java       # Carpet rules (@Rule annotations)
    │   ├── FakePlayerTickStageSettings.java  # TIS same-name rule, registered separately
    │   ├── GhostPearlFixSettings.java        # IGNY same-name rule, registered separately
    │   ├── api/                    # public API for other mods
    │   ├── commands/               # /hfut, /pearltrace and /tradeseq registration + /player tickingStage injection
    │   ├── helpers/                # per-rule handling logic and the GCA menu-button compat
    │   ├── logger/                 # annotation-driven /log framework
    │   │   ├── HFUTLoggers.java    #   declare a @Logger field to register
    │   │   ├── annotation/Logger.java
    │   │   └── callback/LoggerCallback.java
    │   ├── utils/                  # categories / translation loader / text / permissions / mixin plugin
    │   └── mixins/                 # organized as mixins/rule/<ruleName>/, cf. TIS/IGNY
    │       └── carpet/CarpetServerMixin.java  # diagnostic mixin (logs extension registration)
    └── resources/
        ├── fabric.mod.json
        ├── carpet-hfut-addition.mixins.json       # wires the MixinConfigPlugin
        ├── carpet-hfut-addition.accesswidener     # AW (empty by default)
        └── assets/carpet-hfut-addition/
            ├── icon.png
            └── lang/{en_us,zh_cn}.json            # rule docs / categories / messages
```
